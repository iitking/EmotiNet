Deep Learning Pipeline

Bidirectional GRU Neural Pipeline

Bidirectional Gated Recurrent Units (BiGRU) process sequential text in forward and backward directions simultaneously, capturing both past context and future dependencies for superior emotional sentiment nuance.

STAGE 01

Raw Text Tokenizer

Keras Tokenizer with 10,000 max words vocabulary and OOV token handling.

Output: Int Sequences
STAGE 02

Pad Sequences

Fixed sequence length of 50 tokens with post-padding and truncating.

Shape: (Batch, 50)
STAGE 03

Dense Embedding

Projects discrete tokens into continuous 300-dimensional vector representations.

Dim: 10,000 → 300
STAGE 04 (CORE)

BiGRU Stack + Dropout

Bidirectional GRU (128 units) → Dropout 0.5 → BiGRU (64 units) → Dropout 0.5.

Bi-directional Context
STAGE 05

Softmax Dense Layer

Outputs calibrated probability distributions over 6 emotion classes.

Classes: 6 (Sum = 1.0)

REST API Integration

Integrate EmotiNet prediction endpoint into your Python, Node.js, or mobile applications

Interactive Swagger UI
cURL (Terminal) 
curl -X POST "http://localhost:8000/api/predict" \
  -H "Content-Type: application/json" \
  -d '{"text": "I am so excited and proud of our team success!"}'
Python (requests) 
import requests

url = "http://localhost:8000/api/predict"
payload = {"text": "I feel so grateful for all the love and support."}

response = requests.post(url, json=payload)
data = response.json()

print(f"Predicted: {data['predicted_emotion']} ({data['confidence_percentage']}%)")
print(f"Probabilities: {data['probabilities']}")
JavaScript (fetch) 
const response = await fetch("http://localhost:8000/api/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: "I am absolutely shocked by the sudden turn of events!" })
});

const result = await response.json();
console.log(result.predicted_emotion, result.confidence_percentage);
